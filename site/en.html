What this application is

gMatch is a Windows program (a single .exe, no installation) that works as an adult social network + card-game arcade. It combines:

  • A feed of photos/videos YOU publish, with per-post sharing choices;
  • Private chat and group rooms with end-to-end encryption;
  • An adult idle-clicker and a 1v1 card game with decks, an internal store and a player market;
  • Denunciation-based moderation: whoever receives an offensive message can report it and only then reveal it to a moderator.

No sign-up, no e-mail, no phone. Your "account" is a cryptographic keypair generated on your computer. You are the only one responsible for keeping the secret key safe (the app offers a file backup).

Security: what the server can and cannot see

The server hosting this page runs only the download and a minimal "blind courier". By design (audited — links below):

  • All content (messages, photos, captions, rooms) travels encrypted. The server forwards opaque envelopes addressed to tokens: it does not know who sends, to whom, or what is inside.
  • The server keeps no list of who is online: connections are anonymous; presence exists only among your contacts.
  • The app caches nothing to your disk: feed images live only in session memory; every server response is marked no-store.
  • Your private keys stay on your Windows protected by Windows' own crypto system (DPAPI) — never in plaintext, never on the server.
  • IP addresses are not recorded in application logs; the TURN relay uses random short-lived credentials unlinked to your identity.
  • You can skip our server entirely: the app can point to a server you (or a friend) run, keeping everything inside your network.

Read the full security report: security audit. The code is open: github.com/9matesu/goongrid.

Cryptography and how it works (no mystery)

  • Identity: on first start the app generates two keypairs — Ed25519 (signs your actions) and X25519 (encrypts content). Your "ID" is a cryptographic digest (SHA-256) of the public key. The private key never leaves your device.
  • 1:1 messages: ECIES (X25519 + BLAKE3 + XChaCha20-Poly1305). Mathematically, only the holder of your private key can open what was sent to you — not the server, not even the sender afterwards.
  • Group rooms: a shared secret (DEK) circulates encrypted between invitees; when someone leaves, the secret rotates (epoch) — past messages stay readable to members, nothing new opens with the old key.
  • Request authentication: every API call is signed and timestamped; replayed requests are rejected.
  • P2P privacy: ICE candidates containing literal IPs are dropped before leaving the app; the relay is optional and randomly labelled.
  • Honest limit: cryptography protects content from third parties; it does NOT protect against someone stealing your unlocked computer or your exported key. Keep your key backup somewhere safe.

"Windows said it might be dangerous" — why, and what to do

The SmartScreen warning appears for ANY legitimate unsigned program — it is not a virus indicator. This executable has no commercial signature (it costs hundreds of dollars per year and we fund the project with donations, not data sales). To trust it independently:

  1. Verify the SHA-256 (below) — proof the downloaded file is exactly what we published;
  2. Paste the hash or upload the file for analysis at VirusTotal (public scan by ~70 antivirus engines);
  3. Or skip the .exe: clone the open-source code and build it yourself: github.com/9matesu/goongrid (commands in README.md — npm install, npm run dist).

Verify the hash on Windows (20 seconds, no install)

Open the Start menu, type PowerShell, open it and run (adjust the path if you saved elsewhere):

Questions you would ask

Why an .exe instead of a website?

So adult content never passes through nor sits on a third-party web host: the app runs on your machine and only ever sends encrypted envelopes. A normal website cannot hide from its host what it displays.

Can I recover my account if I lose the key?

No — and that is on purpose (nobody, not even us, can get into your account). That is why the app insists on a key backup/export.

Any telemetry, ads, sign-up?

No. Zero analytics, zero cookies on this page, zero sign-up.

What does the server actually store?

In official mode: encrypted envelopes with an expiry (up to 7 days until the recipient fetches them) and a delivery token that is a mathematical digest of the recipient's public key. Nothing that points to a person.
