# Plan: Video Preview, Spurious Card Minting, Username Alignment

## Goal

Fix four bugs: videos showing "No Preview" on profile grid, posts/stories auto-minting cards into other users' collections, stale backfill cards polluting collections, and username misaligned with date/time in feed post headers.

## Current Context / Assumptions

- Repo root: `I:/goongrid` (monorepo: `apps/api`, `apps/desktop`, `packages/shared`)
- Profile grid uses `ObjectImage` with `autoPlay={false}` and no `controls` — hits the bare `<video>` branch (line 237-253 of ObjectImage.tsx) which renders a black frame for MP4s without a poster
- Cards are minted ONLY via explicit `POST /api/cards` (route in `apps/api/src/routes/cards.ts` calls `CardService.createCard()`) — no auto-mint on upload exists in current code
- Migration `035_card_economy_backfill.sql` (lines 33-55) bulk-inserted Cards for ALL non-public, non-story objects — this is the source of "others' posts appearing as cards"
- `mergeMyCards()` in `cardCollection.ts` line 226 filters by `owner_id === ownerId` but legacy backfill cards may have wrong ownership or appear through canonical card joins
- Feed post header (GMatchFeed.tsx lines 774-788): author name has `leading-none`, timestamp has no alignment class — causes vertical misalignment

## Architecture / Proposed Approach

Four independent fixes touching minimal files: add video poster fallback in ObjectImage, verify no server-side auto-mint exists, write a cleanup migration for backfill cards, and fix CSS alignment in the feed header. No new abstractions.

The `#t=0.5` fragment tells the browser to seek 0.5s for the poster frame. For object URLs (blob:), this doesn't work — so also pass `mimeType` through to `GMatchProfile.tsx` grid calls if needed. **Better fix** — add `preload="metadata"` to force first-frame load:

### Task 3: Cleanup migration for spurious backfill cards

**Root cause:** `035_card_economy_backfill.sql` lines 35-55 created Cards for ALL `is_public=0, is_story=0` objects regardless of whether they were intended as game cards. DM attachments, private uploads, etc. all got carded.

**File:** Create `I:/goongrid/apps/api/migrations/036_cleanup_spurious_cards.sql`

```sql
-- Remove cards that were auto-backfilled from non-card objects.
-- A legitimate card has an entry in CardHistory with event != 'backfilled',
-- or was explicitly created via POST /api/cards (source != 'backfill_v1').
-- Backfill-only cards with no gameplay history are safe to remove.

DELETE FROM CardOwnership
WHERE card_id IN (
  SELECT c.id FROM Cards c
  WHERE c.moderation_state = 'active'
    AND NOT EXISTS (
      SELECT 1 FROM CardHistory h
      WHERE h.card_id = c.id AND h.event != 'backfilled'
    )
    AND NOT EXISTS (
      SELECT 1 FROM MatchPairs mp WHERE mp.card_a = c.id OR mp.card_b = c.id
    )
    AND NOT EXISTS (
      SELECT 1 FROM GameMatches gm WHERE gm.card_a = c.id OR gm.card_b = c.id
    )
    AND NOT EXISTS (
      SELECT 1 FROM DeckCards dc WHERE dc.card_id = c.id
    )
    AND NOT EXISTS (
      SELECT 1 FROM MarketListings ml WHERE ml.card_id = c.id
    )
);

DELETE FROM CardHistory
WHERE card_id IN (
  SELECT c.id FROM Cards c
  WHERE NOT EXISTS (
    SELECT 1 FROM CardHistory h
    WHERE h.card_id = c.id AND h.event != 'backfilled'
  )
  AND NOT EXISTS (
    SELECT 1 FROM MatchPairs mp WHERE mp.card_a = c.id OR mp.card_b = c.id
  )
  AND NOT EXISTS (
    SELECT 1 FROM GameMatches gm WHERE gm.card_a = c.id OR gm.card_b = c.id
  )
  AND NOT EXISTS (
    SELECT 1 FROM DeckCards dc WHERE dc.card_id = c.id
  )
  AND NOT EXISTS (
    SELECT 1 FROM MarketListings ml WHERE ml.card_id = c.id
  )
);

DELETE FROM Cards
WHERE id IN (
  SELECT c.id FROM Cards c
  WHERE NOT EXISTS (
    SELECT 1 FROM CardHistory h
    WHERE h.card_id = c.id AND h.event != 'backfilled'
  )
  AND NOT EXISTS (
    SELECT 1 FROM MatchPairs mp WHERE mp.card_a = c.id OR mp.card_b = c.id
  )
  AND NOT EXISTS (
    SELECT 1 FROM GameMatches gm WHERE gm.card_a = c.id OR gm.card_b = c.id
  )
  AND NOT EXISTS (
    SELECT 1 FROM DeckCards dc WHERE dc.card_id = c.id
  )
  AND NOT EXISTS (
    SELECT 1 FROM MarketListings ml WHERE ml.card_id = c.id
  )
);
```

This deletes only cards that: have no non-backfill history, were never used in matches, never decked, never listed. Pure orphan backfill noise.

## Risks, Tradeoffs, Open Questions

- **Task 1:** `preload="metadata"` on blob URLs works in Chromium/Electron but may not load first frame for all codecs. If MP4s still show black, need to generate poster thumbnails server-side.
- **Task 3:** Migration 036 is destructive — cards deleted cannot be recovered. Safe because we only target cards with zero gameplay history and no deck/market usage. Run on staging first.
- **Task 3:** If "others' posts appear as cards" is actually a `mergeMyCards` client bug (not backfill), the migration won't fix it. Need to verify `GET /api/cards` scope.
- **Task 4:** `leading-none` on `<time>` might clip descenders in some locales. If observed, use `leading-tight` instead.
