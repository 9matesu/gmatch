# Wave 4: P2P Alignment & Media Decentralization Plan

## Goal
Eliminate central node media/route dependencies, ensure strict separation of posts versus canonical cards with orphaned entity cleanup, restore tag-steered randomized idle clicker feeds with top-bar layout controls, fix watch party overlay/context-menu visibility, and standardize all UI audio to short atonal clicks.

## Current Context & Assumptions
- **P2P Transition**: The platform transitioned from central server storage to local client storage (IndexedDB `objects` store) and WebRTC/blind-courier gossiping. Central endpoints rejecting uploads or obsolete routes (`/api/pm/read`, unhandled `/api/watchparty` 422, `/api/users/profile` 400) produce client console errors.
- **Card vs Post Contamination**: P2P image announcements and incoming raw objects (`p2p-obj-*`) were indiscriminately merged into `items` via `mergeMyCards`, flooding user collections with unminted, undeletable cards authored by "Unknown User" missing rarity/mint status.
- **Audio Overlap**: Uploading a post fires `playWin()` (a 5-chord tonal chime in `apps/desktop/src/utils/sounds.ts`), violating the design mandate for a single global atonal click (`playPress`).
- **Idle Clicker Layout & Logic**: Grid size buttons (`1x1`, `2x2`, `3x3`, `4x4`) were relocated to the bottom floating pill bar (`CommandIsland.tsx`) instead of resting on top of the game header (`GoonPanel.tsx`). Cache retrieval displays deterministic ordering instead of randomized tag-steered selection.
- **Watch Tab Overlays**: `WatchPartyView` sits at `absolute inset-0 z-20` outside the flex flow in `App.tsx`, obscuring side rails (`MessagesRail` notifications/alerts). `ContextOverlay` sits at `--z-modal` (50) earlier in the DOM than `WatchPartyView` modals, preventing right-click menus on watch inputs.
- **Author Navigation**: Clicking a post author triggers a profile-picture lightbox or story sequence rather than directly opening the user profile modal (`UserProfileModal.tsx`), and author header text alignment is vertically misaligned relative to the avatar.

## Architecture & Proposed Approach
Enforce a strict boundary between ephemeral feed posts (`/api/posts`, `is_public: 1`) and canonical minted cards (`/api/cards`, `Cards` schema), isolating `mergeMyCards` exclusively to validated card instances and purging local IndexedDB orphans. Decouple client telemetry from missing central routes by routing PM read states through local courier stores, gracefully validating profile patch payloads, and sanitizing Watch Party media inputs. Move layout selectors back to `GoonPanel` headers, shuffle booru feeds weighted by active tags, elevate context overlays to `--z-system` (80), and restrict author clicks strictly to `onSelectUser`.

- **Files**:

- **Context**: Retrieved pictures repeat in deterministic order. Active tags must steer the feed while preserving randomized ordering within tag results.
- **Action**:
  1. In `apps/desktop/src/game/store.ts`, implement Fisher-Yates shuffle on retrieved booru cache posts when populating cells:
  ```typescript
  export function shuffleFeedPosts<T>(items: T[]): T[] {
    const shuffled = [...items];
    for (let i = shuffled.length - 1; i > 0; i--) {
      const j = Math.floor(Math.random() * (i + 1));
      [shuffled[i], shuffled[j]] = [shuffled[j], shuffled[i]];
    }
    return shuffled;
  }
  ```
  2. Ensure tag filtering is strictly applied before randomizing:
  ```typescript

      activeTags.some((tag) => post.tags?.includes(tag.toLowerCase()))
    );
  }
  const randomized = shuffleFeedPosts(eligible);
  ```

## Risks, Tradeoffs & Open Questions
- **IndexedDB Cleanup Safety**: Purging orphaned `p2p-obj-*` items from IndexedDB should only target unminted items with author `Unknown User` to avoid deleting legitimate locally saved assets.
- **Tag Steer Strictness**: If a user selects 5 niche tags that return 0 matches from booru caches, fallback behavior should gracefully notify the user rather than hanging the idle clicker stage.
- **Central Node Fallbacks**: As the server continues operating in Zero-Fly / Courier mode, all legacy endpoints must be stubbed or cleanly handled client-side to prevent network error spam.
