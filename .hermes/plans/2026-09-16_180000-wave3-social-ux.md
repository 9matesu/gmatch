> **For Hermes:** use subagent-driven-development if available; otherwise execute
> task-by-task in the main turn with strict TDD (RED → GREEN → commit per task).

**Goal:** close the Wave-3 gap list from the 2026-09-16 user brief: unify
context menus, DMs accept images, notifications persist + like notifications,
server browser revamp (one tab, collapsible columns), grid size on the bar,
no-preview/404/idle-vault/mp4 fixes, modal-vs-pill overlap, Stories

context menu item is the keystone: one `ContextOverlay` already exists and is
rich; the fix is to ROUTE section surfaces into it instead of bespoke modals,
not to build a menu system.

**Tech stack:** React 19 + Vite + Tailwind, Zustand, Hono on Bun (apps/api),
Playwright E2E, vitest, electron-builder portable.

## 5. Risks / decisions taken

- **Two menus, one item.** Tasks 1-2 route surfaces into `ContextOverlay`; the
  alternative (make `PostOptionsModal` the menu) was rejected because the
  overlay already carries 20+ callbacks and the DESIGN.md idiom.
- **`ContextMenuType` union.** `App.tsx:635` narrows to `'user' | 'item'`;
  expanding it is the smallest change but touches every call site's types —
  expect tsc to name them. Fix at the union, not per caller.
- **Server browser scope.** The revamp is the largest item; the plan caps it
  at honesty + empty-state + collapse. Full information-architecture redesign
  is a follow-up if the cap is hit.
- **mp4 disk cache.** Deliberately left RAM-only this wave (documented with a
  `ponytail:` comment). Say so if restart-seek matters.
- **Stories scope.** Six behaviours, six commits. If Instagram-exact segment
  geometry fights the existing CSS, land the 3 functional ones (advance,
  pause, viewers) and file the geometry as a follow-up.
- **`design-gates.sh`** is the honest gate for Tasks 5/6/10 — run it after
  each, not once at the end.
- **Shared worktree.** If another agent is in this tree, commit explicit paths
  only and re-check `git branch --show-current` + `git log --oneline -3`
  immediately before every commit.
