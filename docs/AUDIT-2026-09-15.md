  multi-isolate needs Durable Object counters).

## Presence wave (same day, ghost-roster fix)

`last_seen` write contract — presence is written ONLY by: the heartbeat route,
lobby join/autoQueue/snapshot, profile PATCH, first-time auth auto-register
(INSERT), and the WS-close negative mark. The auth middleware no longer
refreshes `last_seen` on every signed request (`DO UPDATE` -> `DO NOTHING`):

marks offline for ANY authed socket (watch/chat-only users included), guarded

returns Followers-table-derived counts like every other read, so the
profile's own counter can't outpace the modal list. Locked by tests in
`routes/auth-middleware.test.ts` + `routes/users-follow-counts.test.ts`.
